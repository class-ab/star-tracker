# star-tracker
open source star tracker.

### goal: 
accurate tracking of polar axis for long-exposure photography.

### method:
cheap, commonplace electronics components and 3D printed parts, but perhaps with a little PCB spice.

### criteria:
- sub $100
- camera + counterweight up to 3kg
- mounting for range of cameras/tripods
- manual setup, automatic tracking (=> one motor only)
